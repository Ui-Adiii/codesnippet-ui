### 1. Prerequisites

Before installing CodeSnippetUI, make sure your project meets the following requirements:

- React 18 or later
- Next.js or Vite
- Tailwind CSS v4
- Node.js 18 or later
- [shadcn/ui](https://ui.shadcn.com/) CLI

All CodeSnippetUI components are built with Tailwind CSS v4. Make sure it is properly configured in your project before installing components.

For Next.js, follow the [Tailwind CSS v4 installation guide](https://tailwindcss.com/docs/installation/framework-guides/nextjs).

### 2. Install Utilities

Many components use the `cn` utility function to merge Tailwind CSS classes.

Install the utility using the command below:

<Tabs items={["bun", "npm", "pnpm"]}>
  <Tab value="bun">
    ```bash
    bunx shadcn@latest add https://codesnippet-ui.vercel.app/r/utils.json
    ```
  </Tab>
  <Tab value="npm">
    ```bash
    npx shadcn@latest add https://codesnippet-ui.vercel.app/r/utils.json
    ```
  </Tab>
  <Tab value="pnpm">
    ```bash
    pnpm dlx shadcn@latest add https://codesnippet-ui.vercel.app/r/utils.json
    ```
  </Tab>
</Tabs>

This will automatically add the required utility files to your project.

### 3. Install Your First Component

That's it! You're ready to start installing components.

CodeSnippetUI uses [Lucide Icons](https://lucide.dev/guide/installation) for most icons and selected [shadcn/ui](https://ui.shadcn.com/) components.

When installing a component through the CLI, its required files and dependencies are automatically handled whenever they are declared in the registry.

For example, to install `card-05`:

<Tabs items={["bun", "npm", "pnpm"]}>
  <Tab value="bun">
    ```bash
    bunx shadcn@latest add https://codesnippet-ui.vercel.app/r/card-05.json
    ```
  </Tab>
  <Tab value="npm">
    ```bash
    npx shadcn@latest add https://codesnippet-ui.vercel.app/r/card-05.json
    ```
  </Tab>
  <Tab value="pnpm">
    ```bash
    pnpm dlx shadcn@latest add https://codesnippet-ui.vercel.app/r/card-05.json
    ```
  </Tab>
</Tabs>

Once installed, import the component into your page:

```tsx
import Card05 from "@/components/codesnippetui/card-05";

export default function Page() {
  return (
    <main>
      <Card05 />
    </main>
  );
}
```

You're all set!

<Callout type="info">
  Although we provide a convenient copy button for component code, we strongly recommend using the CLI. It automatically installs the required files and helps maintain the correct project structure.
</Callout>

### 4. Installing Blocks

Blocks are collections of multiple components and files designed to create complete sections or interfaces.

Unlike individual components, blocks may contain multiple dependencies and supporting files. Therefore, we recommend installing them using the shadcn CLI.

For example, to install the `ai-card-generation` block:

<Tabs items={["bun", "npm", "pnpm"]}>
  <Tab value="bun">
    ```bash
    bunx shadcn@latest add https://codesnippet-ui.vercel.app/r/ai-card-generation.json
    ```
  </Tab>
  <Tab value="npm">
    ```bash
    npx shadcn@latest add https://codesnippet-ui.vercel.app/r/ai-card-generation.json
    ```
  </Tab>
  <Tab value="pnpm">
    ```bash
    pnpm dlx shadcn@latest add https://codesnippet-ui.vercel.app/r/ai-card-generation.json
    ```
  </Tab>
</Tabs>

The CLI will install the block along with its declared supporting components and files.

Import the block into your page:

```tsx
import AICardGeneration from "@/components/codesnippetui/AICardGeneration";

export default function Page() {
  return (
    <main>
      <AICardGeneration />
    </main>
  );
}
```

<Callout type="info">
  Some blocks require additional components or dependencies. Check the individual block documentation for installation requirements.
</Callout>

### 5. Optional Dependencies

Some components use additional third-party libraries for animations, icons, charts, or other functionality.

These dependencies are listed at the bottom of each component's documentation.

Make sure to install the required dependencies before using those components.

For example:

```bash
npm install framer-motion
```

> You only need to install the dependencies required by the components you use.

### 6. Monorepo Support

Are you using a monorepo?

The shadcn CLI supports the `-c` option to specify the workspace directory where you want to install components.

For example, if your Next.js application is located inside `apps/www`:

<Tabs items={["bun", "npm", "pnpm"]}>
  <Tab value="bun">
    ```bash
    bunx shadcn@latest add https://codesnippet-ui.vercel.app/r/card-05.json -c ./apps/www
    ```
  </Tab>
  <Tab value="npm">
    ```bash
    npx shadcn@latest add https://codesnippet-ui.vercel.app/r/card-05.json -c ./apps/www
    ```
  </Tab>
  <Tab value="pnpm">
    ```bash
    pnpm dlx shadcn@latest add https://codesnippet-ui.vercel.app/r/card-05.json -c ./apps/www
    ```
  </Tab>
</Tabs>

The CLI will use the specified workspace configuration when resolving the component installation.
